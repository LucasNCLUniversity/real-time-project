# Graphical Real Time

This project is my graphical soloution to time.is (very popular real time website) as the graphics are harsh and unappealing. 
When comparing time.is to my project, my projects accuracy is within 1 second (assuming time.is has 100% accuracy).
Tools used to make this site are:
-Claude by Anthropic #quitgpt (read this article to find out why Sam Altman is a pushover: https://www.bbc.co.uk/news/articles/c3rz1nd0egro) 
-StackOverflow for debugging
-vsCode due to it being the easiest IDE for multi language programs in my opinion.
